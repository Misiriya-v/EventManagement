# EventManagement# Eventora 🎫

A full-stack Event Booking Web App built with MERN Stack and Stripe Payment Gateway.

## Features
- User Authentication (JWT)
- Event Listing & Search
- Seat Booking System
- Stripe Card Payments
- My Bookings Dashboard
- Admin Event Management

## Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Payments: Stripe
